# PapaControl 1차 프로토타입 GDD

## 목표

Phaser 3와 Arcade Physics로 자동 이동하는 2D 플랫포머의 핵심 조작감을 PC와 모바일에서 검증한다.

## 핵심 루프

플레이어는 마지막으로 바라본 방향으로 항상 이동한다. 지면에서는 공처럼 구르는 `roll`, 공중에서는 날개가 나타나는 `fly`가 자동 적용된다. 지상 boost로 tier 0에서 tier 2까지 가속하고, 점프로 수평 모멘텀을 공중에 연결한다. 공중에서는 활공하거나 slam으로 빠르게 착지해 drop boost를 노린다.

## 조작

- PC: `←`/`→` 또는 `A`/`D` 방향 전환, `Space` 점프·활공, `Shift` boost, 공중에서 `↓`/`S` slam.
- 모바일: 하단 좌/우 버튼으로 방향 전환, `FLY` 탭·유지로 점프·활공, `BOOST` 유지로 지상 가속, `SLAM`으로 급강하.
- 좌우 입력 해제는 정지 명령이 아니다. 마지막 방향이 유지된다.

## 속도 tier와 모멘텀

- tier 0: 기본 속도와 자유로운 방향 전환을 제공하는 제어·회복 상태다.
- tier 1: 지상에서 boost를 유지해 tier 2로 가속하는 준비 상태다.
- tier 2: 고속 모멘텀 상태다. 반대 방향 입력 시 즉시 반전하지 않고 감속 후 전환한다.
- boost는 지상에서만 가속력을 만든다. 공중 boost는 이번 핵심 구현에서 제외한다.
- 실제 속도가 tier 경계를 결정하지만 레벨에서는 각 tier의 역할을 기준으로 장애물을 설계한다.

## 상태

### roll

- 지면 접촉 시 자동 진입한다.
- 일정한 수평 속도를 유지한다.
- boost 유지 중 tier 1을 거쳐 tier 2까지 가속한다.
- tier 2에서 반대 방향 입력 시 감속한 뒤 방향을 전환한다.
- 이동 방향에 맞춰 공 그래픽이 회전한다.
- 점프로 fly에 진입한다.

### fly

- 공중 상태에서 자동 진입하며 임시 날개 이펙트를 표시한다.
- 수평 자동 이동을 유지한다.
- 점프 직전의 실제 수평 속도와 tier를 유지한다.
- 점프 입력 유지 중 중력을 크게 줄이고 약한 상승력을 더한다.
- 입력을 놓으면 제한된 최대 속도로 하강한다.
- 지면 접촉 시 roll로 돌아간다.

### slam / drop boost

- 공중에서 slam 입력 시 수평 속도를 줄이고 빠르게 낙하한다.
- 일정 거리 이상 slam한 뒤 착지하면 drop boost가 성공하고 tier 2 속도로 지상 이동을 재개한다.
- 높이가 부족하면 일반 slam 착지로 처리하고 tier 0 속도로 복귀한다.

## 첫 번째 테스트 레벨

1. 시작 평지: 자동 구르기와 방향 전환.
2. 완만한 계단형 슬로프: 경사 이동감.
3. 오르막/내리막 조합: 연속 지형 반응.
4. 상층 플랫폼: 점프와 착지 상태 전환.
5. 비행 전용 공간: 높은 벽과 상단 통로를 활공으로 통과.
6. 도착점: 체크 깃발과 다시 시작 버튼.

각 구간에는 현재 상태, tier, 실제 속도와 고속 반전·slam 여부를 표시하는 디버그 HUD를 제공한다.

월드 하단에는 투명 안전 바닥을 둔다. 추락 감지 시 시작점이 아니라 플레이어가 이미 통과한 가장 가까운 안전 앵커 위로 복귀한다.

## 완료 기준

- PC와 모바일에서 방향 전환, 점프, 길게 눌러 활공이 가능하다.
- 플레이어가 입력 해제 후에도 정지하지 않는다.
- 모든 지형 구간을 통과해 도착 화면과 재시작을 확인할 수 있다.
- 낙사로 게임 진행이 중단되지 않는다.
- `pnpm build` 결과물이 GitHub Pages의 저장소 하위 경로에서 실행된다.
