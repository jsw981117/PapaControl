# PapaControl 1차 프로토타입 GDD

## 목표

Phaser 3와 Arcade Physics로 자동 이동하는 2D 플랫포머의 핵심 조작감을 PC와 모바일에서 검증한다.

## 핵심 루프

플레이어는 마지막으로 바라본 방향으로 항상 이동한다. 지면에서는 공처럼 구르는 `roll`, 공중에서는 날개가 나타나는 `fly`가 자동 적용된다. 플레이어는 방향을 바꾸고, 점프하고, 공중에서 점프 입력을 유지해 추락을 늦추거나 조금 상승한다.

## 조작

- PC: `←`/`→` 또는 `A`/`D` 방향 전환, `Space` 점프, 공중에서 `Space` 유지 시 활공.
- 모바일: 하단 좌/우 버튼으로 방향 전환, `FLY` 버튼 탭으로 점프, 유지로 활공.
- 좌우 입력 해제는 정지 명령이 아니다. 마지막 방향이 유지된다.

## 상태

### roll

- 지면 접촉 시 자동 진입한다.
- 일정한 수평 속도를 유지한다.
- 이동 방향에 맞춰 공 그래픽이 회전한다.
- 점프로 fly에 진입한다.

### fly

- 공중 상태에서 자동 진입하며 임시 날개 이펙트를 표시한다.
- 수평 자동 이동을 유지한다.
- 점프 입력 유지 중 중력을 크게 줄이고 약한 상승력을 더한다.
- 입력을 놓으면 제한된 최대 속도로 하강한다.
- 지면 접촉 시 roll로 돌아간다.

## 첫 번째 테스트 레벨

1. 시작 평지: 자동 구르기와 방향 전환.
2. 완만한 계단형 슬로프: 경사 이동감.
3. 오르막/내리막 조합: 연속 지형 반응.
4. 상층 플랫폼: 점프와 착지 상태 전환.
5. 비행 전용 공간: 높은 벽과 상단 통로를 활공으로 통과.
6. 도착점: 체크 깃발과 다시 시작 버튼.

월드 하단에는 투명 안전 바닥을 둔다. 추락 감지 시 시작점이 아니라 플레이어가 이미 통과한 가장 가까운 안전 앵커 위로 복귀한다.

## 완료 기준

- PC와 모바일에서 방향 전환, 점프, 길게 눌러 활공이 가능하다.
- 플레이어가 입력 해제 후에도 정지하지 않는다.
- 모든 지형 구간을 통과해 도착 화면과 재시작을 확인할 수 있다.
- 낙사로 게임 진행이 중단되지 않는다.
- `pnpm build` 결과물이 GitHub Pages의 저장소 하위 경로에서 실행된다.
