# PapaControl 로드맵

## 완료 — v0.1 프로토타입

- Phaser 3 + TypeScript + Vite + pnpm 프로젝트 구성
- 반응형 캔버스와 Arcade Physics 월드
- 항상 이동하는 roll/fly 플레이어 상태
- 모멘텀 기반 수평 이동과 tier 0~2 속도 상태
- 지상 boost 가속과 tier 2 고속 감속 후 방향 전환
- roll → fly 수평 모멘텀 유지
- slam과 낙하 거리에 따른 drop boost
- 키보드 및 모바일 멀티터치 조작
- 평지, 계단형 슬로프, 경사 조합, 상층, fly 게이트, 도착점 테스트 레벨
- 투명 안전 바닥과 최근 안전 지점 복귀
- 도착 오버레이와 재시작
- Vitest 안전 지점 로직 테스트
- Vitest tier 가속, 공중 모멘텀, 고속 반전, slam/drop boost 테스트
- GitHub Pages 자동 배포 워크플로
